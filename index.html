01function Dijkstra(Graph, source='A'):
02 for each vertex v in Graph.Vertices:
03 dist[v] ← ∞, prev[v] ← null
04 dist[source] ← 0
05 Q ← copy of all vertices in Graph
06 while Q is not empty:
07 u ← vertex in Q with min dist[u]
08 remove u from Q
09 for each unvisited neighbor v of u:
10 alt ← dist[u] + weight(u, v)
11 if alt < dist[v]:
12 dist[v] ← alt, prev[v] ← u
13 return dist, prev
